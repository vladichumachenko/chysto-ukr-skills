# chysto — чиста українська, той самий автор

`chysto` (від «чисто») — скіл для агентів, який очищає український текст від русизмів, кальок
російських сталих зворотів, суржику та айтішного жаргону з російського сленгу. Він зберігає
зміст і голос автора та показує кожну правку з поясненням.

Це перша версія. Репозиторій задуманий як невеликий набір скілів для українського письма.

## Що робить

На вході — Markdown-файл або посилання на опубліковану статтю. На виході — два файли:

- **`<назва>.review.html`** — текст із правками просто в ньому: видалене закреслено червоним,
  нове виділено зеленим, дискусійні поради підкреслено жовтим. Кожна правка має пронумеровану
  виноску: тип (русизм, калька, жаргон, перебудова), рівень (помилка чи порада), причину та
  джерело.
- **`<назва>.fixed.md`** — виправлений текст. Код, формули, посилання й розмітка Markdown
  лишаються байт у байт.

## Принципи

- **Зміст недоторканний.** Правку, що хоч трохи зсуває зміст, не робимо.
- **Стиль автора лишається.** Короткі речення, іронія, розмовна українська та власні образи
  автора — це стиль, а не помилки.
- **Мінімальна правка.** Змінюється лише те, що можна назвати помилкою. Речення перебудовується
  тільки через названу ваду (двозначність, калькована конструкція, розірваний логічний зв'язок,
  перевантаженість).
- **Помилки й поради.** Явні русизми та кальки виправляються; пуристські заміни слів, які
  сучасна норма приймає (наприклад, «за замовчуванням» → «типово»), лише пропонуються.
- **Жаргон — англійською.** Айтішний жаргон із російського сленгу стає англійським терміном
  латиницею: «прод» → production, «викатка» → rollout, «вливаю PR» → «роблю merge PR».
- **Англійські терміни й код не чіпаємо ніколи.**

## Де використовується

Технічні статті й дописи в блогах українською, чернетки, перекладені з російської (людиною чи
машиною), документація та будь-який проєкт, де українські тексти лежать поруч із кодом.

## Встановлення

```bash
npx skills add vladichumachenko/chysto-ukr-skills --skill chysto
```

Скриптам потрібен лише Python 3.9+, жодних пакетів встановлювати не треба.

## Використання

Попросіть агента перевірити український файл або посилання на статтю, наприклад «перевір цю
статтю через chysto». Скіл за потреби завантажить статтю, проскануює її, ухвалить правки й
запише два файли поруч із джерелом.

Щоб захистити власну лексику (сленг, образи, назви продуктів), покладіть у корінь проєкту файл
`chysto-keep.txt` — по одному слову чи звороту в рядку. Скіл їх ніколи не позначає.

Скрипти можна запускати й вручну:

```bash
python3 skills/chysto/scripts/fetch.py URL -o article.md
python3 skills/chysto/scripts/scan.py article.md -o candidates.json
# агент (або ви) пише edits.json на основі кандидатів
python3 skills/chysto/scripts/render.py article.md edits.json
```

## Безпека

Скіл читає тексти, написані іншими людьми, зокрема вебсторінки за посиланням. `SKILL.md`
наказує агентові сприймати такий текст виключно як дані для вичитки: вбудовані в нього інструкції
ніколи не виконуються, посилання з нього не відкриваються, код із нього не запускається.
Сторінка завантажується лише тоді, коли користувач явно дав її адресу; приймаються тільки адреси
`http(s)`. Скрипти використовують лише стандартну бібліотеку Python і записують тільки два вихідні
файли та JSON-файли поруч із джерелом.

## Джерела

- **LanguageTool**, український модуль (https://github.com/languagetool-org/languagetool),
  коміт `c5b1ab8`: таблиці замін русизмів і виправлені приклади правил про барбаризми —
  `skills/chysto/data/lt-replace.tsv`, близько 10 400 записів. Ліцензія LGPL 2.1; див.
  `skills/chysto/data/NOTICE-languagetool.md`.
- **С. Іваницький, Ф. Шумлянський, «Російсько-український словник»** (Вінниця, 1918; близько
  35 000 статей), оцифрований зі скану перевидання 2006 року — лише словникові статті, які є
  суспільним надбанням: `skills/chysto/data/slovnik1918.tsv`. Словник укладали, щоб відмежувати
  українську лексику від російської; він дає синонімічні ряди з наголосами. Чимало його лексики
  сьогодні архаїчне, тож він постачає кандидатів, а не готові заміни.
- **Списки chysto** — кальки сталих зворотів і правила для жаргону, зібрані на реальних технічних
  статтях: `chysto-calques.tsv`, `chysto-jargon.tsv`. Під час їх укладання заміни звірялися зі
  «Словником складної лексики» С. Караванського та «Російсько-українським словником ділової
  мови» (1930), які доступні на [r2u.org.ua](https://r2u.org.ua). Їхній вміст до репозиторію
  не входить.

Сучасна норма, на яку спираються рішення, — словник СУМ-20 і Правопис 2019.

## Обмеження

- Слова зіставляються простим відкиданням закінчень, без повного морфологічного словника:
  сканер шукає кандидатів широко, а рішення ухвалює агент.
- Словник 1918 року оцифровано за допомогою OCR; близько 6 % статей позначено як ненадійні.
- Перша версія працює з лексикою, сталими зворотами, жаргоном і перебудовою через названі вади.
  Окремо орфографію, пунктуацію й типографіку вона не перевіряє.
